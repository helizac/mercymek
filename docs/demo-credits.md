# Demo credits

Application: mercymek, voice-driven crash reconstruction.
Screen recordings, editorial title cards, narration script, captions and edit were
created for this submission. English narration was generated with ElevenLabs,
using the configured Sarah voice and Eleven v4; application replies use Eleven v4 Turbo.
No background music is included. Spoken demo commands are prerecorded ElevenLabs
audio sent through the real browser microphone pipeline and Muse Voice ASR.
Processing waits are shortened with cuts; findings are not fabricated.

## Footage visible in the film

- **London rear-end:** Dash Cam Owners World, “Cash For Crash BMW LM58BLZ Caught On Dashcam A10”.
  [Original video](https://www.youtube.com/watch?v=V758npfi-w4),
  [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
  Trimmed excerpt, face redaction, original-frame plate evidence, visual geolocation
  clues, vehicle dossiers, source files, derived enhancement and a labelled
  estimated 3D comparison and the actual web-app 3D interface are shown. The source title is attribution,
  rather than an investigative finding about intent.

Map data: OpenStreetMap contributors, ODbL, with attribution visible in the map.
See the repository README for model, renderer and other dependency licenses.
Generated geometry, inferred motion, synthetic slow-motion frames and blueprint
illustrations are labelled in the interface; they are distinct from original footage.

Keep these credits with the submitted video and include the source links in the
description when uploading it.
